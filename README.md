# Turni Lorena

Webapp che converte gli screenshot mensili di **Shifter** in eventi per il Calendario di iPhone.

1. Apri la pagina in Safari e carica uno o più screenshot.
2. Controlla i turni riconosciuti (tocca un giorno per correggerlo o aggiungere una nota).
3. Tocca **Aggiungi al Calendario**, scegli il calendario "Turni Lorena" e poi **Aggiungi tutto**.

| Sigla | Evento | Orario |
|---|---|---|
| G | Turno Giorno | 07:00 → 19:00 |
| N | Turno Notte | 19:00 → 07:00 (giorno dopo) |
| CS | Corso | 08:30 → 16:30 |

Le sigle e gli orari si modificano dalla pagina ("Sigle e orari") e restano salvati nel browser.
Tutto avviene nel telefono: le immagini non vengono caricate da nessuna parte.
